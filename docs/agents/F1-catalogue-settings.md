## Catalogue (`/admin/catalogue`, per selected venue; owner and managers only, staff see read-only)
Phone-first forms with the UI kit. Each change is a server action that validates (zod), writes, audits (`before`/`after`), and `revalidatePath`. Edits take effect on the next availability call (sessions are reconciled by `ensureSessions`; for a capacity or timetable change call `ensureSessions` for the next 62 days after saving so the Today/Week views update at once).
- **Services list** (`/admin/catalogue`): cards in sort order with kind badge, length, online on/off, pay-in-store on/off, archived hidden behind a toggle. "Add service" (kind, name, room, length, interval for slots, lead time, cut-off, colour). Reorder with up/down buttons (sortOrder swap).
- **Service detail** (`/admin/catalogue/[serviceId]`): tabs or stacked sections: Details (name, blurb, room, length, slot interval, lead time, cut-off, online enabled, pay-in-store, in-store note line/short/menu URL, colour, archive/restore); **Options** (name, blurb, price in pounds input converted to pence, included children for slots, max per booking, in-store notes; add / edit / archive); **Add-ons** (name, blurb, price, kind quantity|time, extra minutes, max quantity, per-child; add / edit / archive); **Timetable** (sessions only): a weekday × start-time grid of rules with capacity; "Add times" form (weekdays multi-select, start time, capacity, valid from/to), delete rule; a helper "Fill from opening hours" that creates hourly rules from the venue's opening hours to one length before close (confirm first; replaces nothing, only adds missing); **Exceptions**: list upcoming (date, time or whole day, kind, capacity, note) with add (cancel day / cancel one time / add a session at time with capacity / change capacity) and delete.
- **Blocks** (`/admin/catalogue/blocks`): upcoming blocks for the venue (whole venue or one room), add (room or whole venue, start date+time, end date+time, reason: closed day / private hire / other text), delete. A quick "Close a whole day" shortcut (date → 00:00–24:00 local).
- **Sessions** (`/admin/catalogue/sessions?date=`): the materialised occurrences for a day with capacity and places taken; actions: change this occurrence's capacity (sets `pinned`), cancel this occurrence (status cancelled, pinned; refuse when it has confirmed bookings unless the user ticks "I will move or cancel the N bookings myself"), add an extra session (time + capacity → timetable exception `add` + ensureSessions). (Agent C built `/admin/sessions/[id]` as a read view; link to it, do not edit it.)
