## Reminders job
For every confirmed booking whose `startsAt` is between `now + (reminderHoursBefore − 1h)` and `now + reminderHoursBefore + 1h`… no: simpler and idempotent: every confirmed booking with `startsAt` within the next `reminderHoursBefore` hours (from the organisation) and `startsAt > now` and `reminderSentAt IS NULL` → `sendBookingEmail({ template: "reminder", dedupe: true })`, then set `reminderSentAt`. Skip bookings created less than 2 hours before the start (they just got a confirmation). Summary `{ sent, skipped }`. Hourly cron, so a booking is reminded roughly 24h before, once.

## Retention job
Bookings with `endsAt < now − retentionMonths` and not yet anonymised: replace `customerMessage`, `notes`, `birthdayChildFirstName` with null, set `anonymisedAt`; for customers whose every booking is anonymised (or who have none newer than the cutoff): set firstName "Anonymised", lastName "", email `anon-<id prefix>@anonymised.local`, phone null, notes null, `anonymisedAt`. Also delete notifications older than the cutoff (body snapshots hold personal data) and audit rows older than cutoff + 12 months are kept (audit is retained longer; note it). Summary counts. Daily cron.

## `scripts/import-wix.ts`
`npm run import:wix -- path/to/file.csv [--dry-run]`. CSV columns (header names, case-insensitive, extra columns ignored): `reference, venue, service, start, first_name, last_name, email, phone, places, paid_total, birthday_child, notes`. `venue` is a slug or name; `service` matched by name (case-insensitive) within the venue; `start` ISO or `YYYY-MM-DD HH:mm` London time; `places` for sessions is the count of the first option (if the service has two options, a `places_<option name slug>` column splits them, e.g. `places_slime-workshop,places_decoden-craft-workshop`); `paid_total` in pounds. Creates confirmed bookings via `createManualBooking` with `ignoreTiming`, source `import`, paymentMethod `imported` (payments row provider `import`, method `imported`, amount from `paid_total`), `notes` prefixed with `Wix ref <reference>`; no emails; calendar create. Skips rows whose reference already appears in a booking's notes (re-runnable). Prints a table of created/skipped/failed rows. Use a tiny CSV parser you write (quotes, commas, CRLF), no new dependency. Put the pure parsing/mapping in an exported function so the unit test covers it. Provide `docs/wix-import-sample.csv` with three rows.
